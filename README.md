# Three Interfaces

A single site with **three full interfaces**. Press **`/`** anywhere to switch from one to the next (cycles 1 → 2 → 3 → 1).

| # | Interface | File |
|---|-----------|------|
| 1 | AV — Digital Designer (dark portfolio) | `designer.html` |
| 2 | One Task at a Time (purple SaaS landing) | `saas.html` |
| 3 | Navia — Frontend Developer (3D portfolio) | `navia.html` |

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000  then press "/"
```

## Stack

Plain HTML / CSS / vanilla JS — no build step. Static hosting compatible (GitHub Pages).
