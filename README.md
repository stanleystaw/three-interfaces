# three-interfaces — 48 interfaces, gallery + full site recreations

Live: https://stanleystaw.github.io/three-interfaces/

## What's here
- `index.html` — gallery of 48 interfaces (3 original + 45 recreations), filters, credits to image sources.
- `designer.html` · `saas.html` · `navia.html` — the three hand-built original interfaces (Anton/Inter/Poppins themes).
- `p01.html`–`p45.html` — **full site recreations** of the 45 reference screenshots: every page is rebuilt section by section (top nav, hero with real headline copy, feature grids, marquees, panels, mood/avatar sheets, stats, CTA, footer) with animations — scroll reveals, count-up stats, marquee loops, hover lifts/glow, CTA sweep.
- `css/site.css` — shared recreation design system (themes dark/saas/d3, section vocabulary, motion, reduced-motion support).
- `css/designer.css` `css/saas.css` `css/navia.css` — styles for the three originals.
- `js/site.js` — reveal/count-up/observer runtime. `js/keys.js` — `/` cycles all 48 interfaces, `Esc` → gallery. `js/gallery.js` — cards link to pages, filters.
- `assets/gallery/` — the 48 reference images (+ thumbs). `assets/pages/pNN/` — per-page crops cut from each reference and used as the page's visual elements (no AI image generation).

## Page map
- p01–p10 = gallery g01–g10 (dark creative sites)
- p11–p45 = gallery f01–f35 (dark / SaaS / 3D, in order)

## Navigation
- `/` — cycle to the next interface (wraps 48 → 1)
- `Esc` — back to the gallery
- Gallery card — opens that interface's page

## Build
Pages are generated by `/home/user/build_sites.py` with configs in `/home/user/cfg_a.py` + `/home/user/cfg_b.py` (section-tuple schema → HTML; palette sampled per reference; crops cut with PIL).
